# Core workflow

Chuẩn này dùng một flow chính: `FE plan` → `FE figma` nếu cần → `FE cook` → `FE review` → `FE test` → `FE pr`.

`FE input-sync` chạy khi có CR/file trả lời/clarification/SRS/Figma update sau planning. `FE quick` chỉ dùng cho task nhỏ, rõ scope và rủi ro thấp.

Mọi artifact Markdown phải viết tiếng Việt. `tracking/workflow-status.md` là file duy nhất được chứa mục `Prompt bước tiếp theo`.
