# Vietnamese Output Rule

- Mọi câu trả lời, heading, checklist, report, decision log và artifact `.md` phải viết bằng tiếng Việt có dấu đầy đủ.
- Không viết tiếng Việt không dấu như `Ke hoach trien khai`, `Cau hoi can xac nhan`, `Khong co blocker`.
- Nếu lỡ sinh không dấu, sửa ngay trong cùng lượt trước khi kết thúc.
- Chỉ giữ nguyên không dấu khi đó là code identifier, command, path, route, package, API field, DTO, enum, error code, query key, branch name hoặc nội dung nguyên văn từ source/SRS.
