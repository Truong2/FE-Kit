# Status và versioning

`tracking/workflow-status.md` sở hữu trạng thái machine-readable và là file duy nhất chứa `Prompt bước tiếp theo`.

Plan version nằm trong `planning/implementation-plan.md` và YAML của `workflow-status.md`. Nếu input-sync làm đổi plan, phải bump version và ghi decision trong `task.md`.
