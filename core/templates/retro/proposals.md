# Đề xuất từ retro

Trạng thái: `Proposed` (agent đề xuất) → `Approved` hoặc `Rejected` (người duyệt) → `Applied` (đã áp dụng). Đề xuất `Approved`/`Applied` phải có Người duyệt.

Phạm vi: `project` (thêm vào `docs/frontend-context/team-rules.md` của repo này) hoặc `upstream` (đề xuất cho kit, xuất bằng `node bin/fe-kit.mjs retro export <thư-mục-retro>`).

Đích: file hoặc mục cần đổi, vd `team-rules.md#cook`, `rule:srs-api-contract.md`, `template:implementation-plan.md`, `gate:<code>`.
