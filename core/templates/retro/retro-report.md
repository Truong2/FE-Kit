# Báo cáo retro

Kỳ: <từ ngày> → <đến ngày>. Số liệu: `retro-data.json` cùng thư mục.

## 1. Số liệu chính

| Chỉ số | Giá trị | Ghi chú |
|---|---|---|
| Task được tính |  |  |
| Tỉ lệ pass ngay lần đầu (theo mode yếu nhất) |  |  |
| Lý do bị chặn nhiều nhất |  |  |
| Nhóm / nguyên nhân gốc của bug nhiều nhất |  |  |

## 2. Vấn đề lặp lại

Mỗi vấn đề dẫn chứng bằng số liệu trong `retro-data.json` (code, nhóm, nguyên nhân gốc, task). Không suy đoán ngoài số liệu.

| Vấn đề | Bằng chứng | Ảnh hưởng |
|---|---|---|
|  |  |  |

## 3. Đề xuất

Chi tiết từng đề xuất ở `proposals.md`. Mọi đề xuất bắt đầu ở trạng thái `Proposed`; chỉ người duyệt mới chuyển sang `Approved`.
